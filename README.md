# Kanso Mail Releases

[中文](#中文) | English

This repository only hosts Kanso Mail installers (in GitHub Releases) and update manifests. It contains no source code.

- Product site: https://kansomail.globularcluster.ca
- Verify every download with the SHA-256 checksums published with each release (`SHA256SUMS.txt`).
- The Windows beta installer is not code-signed; Windows SmartScreen may warn you. See the product site for how to verify and run it.
- If GitHub is not reachable from your network, use the mirror download links on the product site.

Kanso Mail is made by GLOBULAR CLUSTER TECHNOLOGY SOFTWARE LIMITED, Vancouver, BC, Canada.
